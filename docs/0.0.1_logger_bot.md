# Shield Software Sistem Dokümantasyonu
## [v0.0.1] — Discord Bot 2: Loglama (Logger)

Bu belge, Shield Software sisteminde panel ve bot olaylarını ilgili Discord kanallarına loglayan kayıt botunun (Bot 2) yapısını açıklar.

---

### 1. Genel Bakış
Web panelinde, veritabanında veya oyun içi entegrasyonlarda gerçekleşen tüm kritik işlemleri gerçek zamanlı olarak yakalayıp, Discord sunucusundaki ilgili kategorize edilmiş kanallara (Audit Log, Mağaza Log, Başvuru Log vb.) zengin içerikli mesajlar (Embeds) olarak gönderen bağımsız alt bot sürecidir.

### 2. Temel Fonksiyonlar
* **Merkezi Loglama Arayüzü:** `global.logAction` üzerinden gönderilen tüm log taleplerini dinler ve işler.
* **IPC Kanal Yönlendirme:** Orkestratör tarafından gönderilen `LOG_ACTION` sinyallerini yakalayarak ilgili kanalID'sine yönlendirir.
* **Kanallara Göre Ayrıştırma:**
  * Yönetici İşlemleri (Yetki verme/alma, rütbe silme vb.)
  * Başvuru Sonuçları (Onay, ret, inceleme notları)
  * Bağış ve Kredi Hareketleri (Kredi yükleme, mağazadan ürün alma)
  * Sistem Uyarıları ve Hatalar
* **Zengin İçerikli Mesajlar (Embeds):** Logları kimin, ne zaman, hangi hedef üzerinde gerçekleştirdiğini detaylı ve renk kodlu Discord embed mesajı formatında yayınlar.

### 3. İlgili Dosyalar
* **[bots/bot2-logger/index.js](../bots/bot2-logger/index.js):** Logger botunun sinyalleri yakalayıp Discord API üzerinden mesaj gönderdiği ana dosyadır.
