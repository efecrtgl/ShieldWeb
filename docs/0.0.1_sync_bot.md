# Shield Software Sistem Dokümantasyonu
## [v0.0.1] — Discord Bot 4: Senkronizasyon (Sync)

Bu belge, Discord yetki rolleri ile web sitesindeki yönetim rütbelerini ve FiveM oyun içi yetkilerini anlık eşleyen senkronizasyon botunun (Bot 4) yapısını açıklar.

---

### 1. Genel Bakış
Web sitesinde atanmış olan admin yetkilerini, rütbeleri, whitelist durumlarını ve FiveM oyun içi verilerini Discord sunucusundaki rollerle çift yönlü olarak senkronize tutan arka plan hizmet botudur.

### 2. Temel Fonksiyonlar
* **Çift Yönlü Rol Senkronizasyonu:** Discord sunucusundaki rol değişikliklerini dinleyerek web veritabanını günceller veya web panelinden atanan rütbeleri Discord rollerine yansıtır.
* **Whitelist Senkronizasyonu (`SYNC_WHITELIST`):** Başvuru onaylandığında veya admin whitelist verdiğinde IPC sinyali ile Discord sunucusundaki kullanıcıya anında Whitelist rolünü tanımlar.
* **Yetki Kontrolü:** Sunucuda rolü alınan veya değişen yetkililerin web panelindeki yönetim yetkilerini anlık olarak günceller.

### 3. İlgili Dosyalar
* **[bots/bot4-sync/index.js](../bots/bot4-sync/index.js):** Rol ve whitelist senkronizasyon mantığının işlendiği ana süreç dosyasıdır.
