# Shield Software Sistem Dokümantasyonu
## [v0.0.1] — Web Ağ Geçidi (Gateway) & Oturum Yönetimi

Bu belge, Shield Software web arayüzünün, Express.js altyapısının, veritabanı bağlantılarının ve güvenli Discord OAuth2 giriş akışının detaylarını açıklar.

---

### 1. Genel Bakış
Web Ağ Geçidi (Gateway), kullanıcılara ve yöneticilere sunulan web arayüzünün (EJS şablonları) ana giriş kapısıdır. Express.js tabanlı sunucu, veritabanı işlemlerini koordine eder ve Discord API ile entegre çalışarak güvenli kimlik doğrulaması gerçekleştirir.

### 2. Temel Fonksiyonlar
* **Discord OAuth2 Giriş Akışı:** Kullanıcılar siteye girmek için kendi Discord hesaplarıyla yetki verirler. Sunucu, Discord API üzerinden kullanıcının benzersiz Discord ID'sini, kullanıcı adını, profil resmini ve sunucudaki üyelik durumunu doğrular. Giriş adresi `DISCORD_OAUTH_URL` ile sabittir; her girişte yeni bir `state` üretilir, geri dönüşte doğrulanır ve oturum kimliği yenilenir (`routes/auth.js`, `services/discordOAuth.js`).
* **MongoDB Tabanlı Oturum Deposu (Session Store):** Express-session oturumları `connect-mongo` ile MongoDB'deki `sessions` koleksiyonunda saklanır. MongoDB'ye ulaşılamazsa sistem çökmeden bellek deposuna (MemoryStore) geçer.
* **MongoDB Veritabanı Entegrasyonu:** Tüm kullanıcı verileri, başvurular, mağaza ürünleri ve sistem logları Mongoose (MongoDB) şemaları üzerinden kalıcı olarak kaydedilir.
* **Merkezi Konfigürasyon:** Portlar, API anahtarları, veritabanı adresleri ve şifreler tek bir `config.js` dosyasından okunur.

### 3. İlgili Dosyalar
* **[index.js](../index.js), [app.js](../app.js) ve [routes/](../routes/):** Gateway sunucusunun, express rotalarının ve veritabanı bağlantı kodlarının bulunduğu dosyadır.
* **[config.js](../config.js):** Çevre değişkenleri ve sistem konfigürasyon dosyasıdır.
