# Shield Software Sistem Dokümantasyonu
## [v0.0.1] — Discord Bot 1: Doğrulama (Verification)

Bu belge, Shield Software sistemindeki ilk aşama güvenlik ve kimlik doğrulama botunun (Bot 1) işlevlerini açıklar.

---

### 1. Genel Bakış
Kullanıcıların web sitesine giriş yaptıktan sonra veya sunucuya katıldıklarında gerçekleştirdikleri ilk kimlik doğrulama ve doğrulama süreçlerini yürüten bağımsız Discord botudur.

### 2. Temel Fonksiyonlar
* **Discord OAuth2 Eşleşme Desteği:** Web panel üzerinden Discord girişi yapan kullanıcıların hesap bilgilerini alır ve sunucudaki üyelik durumlarını doğrular.
* **Otomatik Rol Tanımlama:** Doğrulama adımlarını başarıyla tamamlayan kullanıcılara ilgili kayıtlı üye rollerini tanımlar.
* **Veritabanı Entegrasyonu:** Kullanıcıların doğrulama durumlarını MongoDB (`DiscordUser` modeli) üzerinde günceller.
* **IPC İletişimi:** Hazır olduğunda ana yönlendiriciye `BOT_READY` sinyali ve istemci kimliğini (Client ID) iletir.

### 3. İlgili Dosyalar
* **[bots/bot1-verification/index.js](../bots/bot1-verification/index.js):** Doğrulama botunun ana mantığının ve komutlarının yazılı olduğu bağımsız bot dosyasıdır.
* **[botHelper.js](../bots/botHelper.js):** Botun hazır olma olayını ve olay dinleyicilerini yöneten yardımcı bileşendir.
